# Fluxo seguro para futuras melhorias

Este projeto público é independente do aplicativo usado no ambiente de trabalho.

Para portar uma melhoria:

1. Identifique a lógica reutilizável, sem copiar dados ou exemplos reais.
2. Reimplemente ou copie somente os trechos necessários neste projeto.
3. Substitua nomes, domínios, filas, URLs e mensagens por exemplos genéricos.
4. Crie ou atualize testes com dados sintéticos.
5. Execute os testes, revise o diff e faça uma busca por dados corporativos antes do commit.

Não use sincronização automática entre os dois projetos. A revisão manual é uma barreira intencional de privacidade e segurança.
